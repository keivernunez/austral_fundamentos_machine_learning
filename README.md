### 📋 Descripción

Trabajo práctico que consiste en el análisis completo de un dataset de salud cardiovascular (`heart.csv`), siguiendo las 5 etapas del flujo de razonamiento en aprendizaje automático:

1. **Elección del dataset** — Justificación de la selección
2. **Identificación del tipo de datos** — Clasificación de variables y detección de target
3. **Análisis exploratorio (EDA)** — Estadísticos, visualizaciones y correlaciones
4. **Propuesta de modelo** — Clasificación binaria fundamentada
5. **Uso previsto** — Contexto de aplicación y consideraciones éticas
